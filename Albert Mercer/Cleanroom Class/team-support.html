Cleanroom Class keeps one set of rooms on this iPhone. Enter the floor size and the target ISO class. The plan shows how many sample points that area needs.

Import the particle counts for each point. The verdict compares each location with the concentration limit and names the class the room reaches. Open the worst point to see which diameter is over the limit.

Share writes a report through the system share sheet. There is no account and nothing to buy.
